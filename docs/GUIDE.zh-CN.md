# PULSE LINK // OVERDRIVE 指南

[在线试玩](https://hitsuki-ban.github.io/PulseLinkOverdrive/) · [日本語](GUIDE.ja.md) · [English](GUIDE.en.md)

## 三种模式

- **DUEL**：与 CPU 标准对战。任一方中央生成列触顶即败。
- **BLITZ**：90 秒对战；若没有提前触顶，时间到后按分数、已施加压力和盘面危险度结算。
- **LAB**：无攻击的练习目标。目标盘触顶会自动重置；自己的中央列仍会触顶结束。

## 核心规则

1. 每次落下一组可旋转的双体块。
2. 三个或更多同色块上下左右连通时会一起消除；重力后再次消除就形成连锁。
3. 白色脉冲块若紧邻本次消除，会被卷入并提供 100 能量。
4. 能量达到 100 后可以攻击或防御；无论选择哪一个，都会消耗全部能量。
5. 攻击从对手盘底抬升普通彩色行，因此也可能替对手接成连锁。防御先抵消来袭行，剩余强度再清理高处块。
6. 只有中央生成列进入隐藏区才会失败；两侧可以堆得更高。

## 操作

| 行为 | 键盘 | 触屏 | 标准映射手柄 |
|---|---|---|---|
| 左右移动 | `←` `→` / `A` `D` | 盘面左右滑动；左右虚拟键 | 左摇杆 / 十字键左右 |
| 软降 | `↓` / `S` | — | 左摇杆下 / 十字键下 |
| 顺时针旋转 | `↑` / `X` / `K` | 点按盘面；旋转虚拟键 | A / Cross |
| 逆时针旋转 | `Z` / `J` | — | X / Square |
| 硬降 | `Space` | 盘面向下滑动；双箭头虚拟键 | Y / Triangle / 十字键上 |
| 攻击 | `C` / `L` | 两盘之间的攻击钮 | R1 / RB |
| 防御 | `V` / `;` | 两盘之间的盾牌钮 | L1 / LB |
| 暂停 / 继续 | `Esc` / `P` | 右上角暂停钮；继续钮 | Start |
| 标题页开始 | `Enter` | 播放钮 | A / Cross |

触屏横向滑动会按距离移动最多五格。不同品牌的手柄标签可能不同；这里采用浏览器标准映射的位置名称。

标题页上的模式、难度、语言和设置请用鼠标/触屏选择，或用键盘的 `Tab` / `Shift+Tab` 移动焦点并按 `Enter` / `Space` 确认；手柄只能直接确认开始，不能浏览这些标题页选项。

## 可访问性与离线

设置中可以分别调整音乐、音效、震屏、减弱动态、颜色纹样和触觉反馈。首次载入会尊重系统的“减少动态效果”偏好；颜色同时用纹样和字形辅助辨认。音频需要第一次点击或按键后才会启动。

通过 HTTPS 或本地服务器首次打开后，Service Worker 会提供离线缓存。若要获得完全独立的离线文件，请运行 `uv run python tools/build_standalone.py`，再打开 `dist/pulse-link-overdrive-standalone.html`。浏览器对安装、振动和手柄的支持可能因设备而异。
