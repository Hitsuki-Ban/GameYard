# V2 关卡／内容审计与 V3 重构记录

审计对象：`紙札疾走録・百鬼祭陣 V2`  
重构结果：`V3.0.0`  
视角：关卡设计、遭遇设计、内容节拍、难度分层、Boss考试与重玩结构。

## 1. 审计方法

本轮没有把“代码可运行”当作内容成立。采用以下路径逐项检查：

1. 从标题开始完整走普通模式，记录每个门、波次、Boss阶段、御守与结算。
2. 将九个 V2 遭遇拆为生成时间轴，统计空场、敌人同时量、敌型组合与清场耗时。
3. 用固定中线、固定左、固定右、迟选门、不用祭印、轻度反应、完整反应等策略比较结果。
4. 检查每一种阵形、御守、敌型、危险区和 Boss 阶段是否真的改变规则。
5. 对照关卡节拍、难度维度、敌人职责和 Boss考试的公开设计资料。
6. 先冻结 V2 问题，再重写内容表；不通过单纯提高 HP 掩盖结构问题。
7. 对 V3 普通／烈祭分别做逐关画面捕获、确定性代理回归、软锁注入和性能压力测试。

V2 的一次完整反应式重跑在第二幕 Boss 失败：前六波均无伤、五次第三档门，但第二幕末正确选择的扇阵无法在屏風面战中形成足够的集中输出。该结果暴露的不是单纯数值偏高，而是“上一关正确答案与下一关考试冲突，且没有修正窗口”。

## 2. V2 缺陷清单

### A. 宏观关卡结构

1. **九波共享同一语法。** 都是门出现、敌人从顶端下移、清空、短停，再重复；敌种变化没有形成新的关卡命题。
2. **三幕没有课程职责。** 看不出哪一关在引入、确认、变奏或综合某个机制。
3. **大量空场来自出生距离，而非有意设计的喘息。** 敌人总从画面顶端进入，玩家在“等敌人进入射程”，不是在阅读下一节拍。
4. **强度曲线近似平直。** 每波都以相近密度持续，缺少明显的上升、峰值、释放和再建立。
5. **幕间主要换背景和数值。** 地点变化没有变成空间规则变化。
6. **前一波的正确构筑可能反向惩罚 Boss。** 第二幕裂变波鼓励扇阵，紧接的屏風面却需要集中单侧火力。
7. **Boss 前没有修正窗口。** 玩家无法知道下一场考试，也无法在上一关正确选择后切回应对阵形。
8. **普通波与 Boss 的学习链断裂。** Boss 攻击并未系统回收该幕关卡刚教授的内容。
9. **第三幕只是混合敌人。** 没有把全部规则组织为可读的综合题。
10. **通关后没有新的内容目标。** 只有分数和纸色，没有独立高难规则集。

### B. 遭遇与敌人

11. **敌型差异主要是 HP、速度和颜色。** 多数敌人不会改变玩家的走位、目标优先级或攻击角度。
12. **小幅随机横向抖动被当成变化。** 它增加噪声，却没有产生新的决策。
13. **所有敌人使用同一进场方向。** 无锁定冲锋、驻留召援、半场压迫等空间语法。
14. **关卡容易退化为中线站桩。** 对称编队过多，玩家没有改变横向位置的理由。
15. **投手可能形成软锁。** 防御阵形可以持续拦截弹丸，却无法击中偏轴驻留敌人；敌人又不会重新前进。
16. **召援型内容不存在。** 玩家不需要判断“先打谁”。
17. **盾鬼的方向盾可感知度不足。** 高弹幕下更像额外血条，而非换线题。
18. **裂变体只有死亡后多两个敌人。** 缺少与祭印、范围攻击的明确互动说明。
19. **普通波几乎没有危险区。** 走位规则只在 Boss 突然出现。
20. **清场条件会等待无害投射物结束。** 节拍有时由残留对象拖长，而不是由内容作者控制。
21. **波次没有名称和记忆点。** 玩家难以复盘“哪一关学到了什么”。
22. **敌人预告依赖抽象标签。** 不能保证预告与实际编队一一对应。

### C. 倍率门与构筑

23. **每关保证出现“正确反制门”。** 选择退化成读题找标准答案，而不是构筑取舍。
24. **门只解决紧随其后的单波。** 缺少当前安全与长期成长的冲突。
25. **换门没有实际代价。** 玩家可以先给一侧充能，临近时再换另一侧。
26. **门充能随当前火力和人数增长。** 强局更容易拿高档门，形成富者愈富的雪球。
27. **门停留时间过长。** 迟选仍能轻易拿第三档，承诺机制没有成立。
28. **阵形门藏有额外火力、节奏和人数。** 图标承诺与实际效果不一致，关卡平衡难以阅读。
29. **重复或封顶奖励仍会出现。** 有些门在当前 Build 下几乎没有价值。
30. **Boss 之前仍按普通波生成门。** 没有专门的 Boss 准备设计。
31. **御守只有两次选择，但关联当前构筑较弱。** 三张牌更像独立数值包。
32. **振舞い飯发生重复恢复。** 选取当下和幕间都结算，强度超出文本承诺。
33. **大幟几乎只影响结算分数。** 不能改变局中玩法。
34. **普通玩家可以完全不主动使用祭印。** 自动触发替玩家完成了核心高潮操作。
35. **最高等级没有强制验证核心动作。** 高分可能掩盖门承诺或祭印使用不足。

### D. Boss 内容

36. **高 DPS 可以跳过攻击。** HP 阶段转换时清空危险区和弹丸，强 Build 反而看不到内容。
37. **阶段切换是纯血量阈值。** 没有要求玩家完成或理解本阶段的签名攻击。
38. **强局 Boss 过短，弱局 Boss 过长。** 内容密度与构筑强度呈反向关系。
39. **狂暴只惩罚弱局。** 强局在狂暴前结束，无法增加高手压力。
40. **三个 Boss 的机制差异不足。** 外形和数值变化大于学习要求变化。
41. **预兆缺少层级。** 普通扫荡、半场封锁和终极攻击的视觉语言不够分明。
42. **最终 Boss 缺少高潮保证。** 可以在主要组合尚未出现前被消灭。

### E. 难度与重玩

43. **没有高难度模式。** 不能为熟练玩家提供失败压力。
44. **若直接提高 HP／速度，会扩大数值门而非技巧空间。** V2 没有为独立难度准备内容接口。
45. **难度维度过少。** 主要考查 DPS 和最后一刻横移，几乎不考查规划、优先级、预兆记忆和主动资源。
46. **固定站位偶尔能因门序滚起雪球。** 策略质量与结果关系不稳定。
47. **优秀操作和普通通关的区分不足。** 只有总分大数，没有清晰的行为评价。
48. **存档没有普通／高难分离。** 即使追加难度也无法形成独立追求。
49. **首局缺少无文字教学。** 玩家能移动，但不一定立即理解“要提前选边并射门”。
50. **重玩变化依赖随机门边。** 遭遇本身几乎固定。

## 3. 关联设计资料得出的约束

### 3.1 强度不是一直更高

Valve 在《Left 4 Dead》的 AI Director 说明中，将体验组织为强度建立、峰值、放松与再建立；Boss 与事件也受节拍控制。V3 因此把每波拆为三个鼓点，使用短暂空场加速、接敌减速和明确清场，而不是让敌人永远从远处慢慢走来。

### 3.2 难度是多维向量

GDC 2022《1000 Hours of Difficulty》强调反应、精度、规划、知识与空间推理等不同难度维度。烈祭因此同时收紧：

- 反应：更短的冲锋锁定与危险区预兆；
- 规划：门必须更早承诺；
- 知识：敌型与阵形相克；
- 空间：重叠半场、交叉扫荡和群体真实宽度；
- 资源：祭印不再自动触发；
- 优先级：投手、鼓鬼、冲锋鬼必须先处理。

HP、速度和伤害只作辅助倍率。

### 3.3 快敌与慢敌承担不同压力

《Assault Android Cactus》的公开演讲将高速敌人用于压缩喘息，将慢速大群用于制造位置压力。V3 的駆鬼／駆矢鬼负责反应与换位，鎧鬼／盾鬼负责空间占据，投手／鼓鬼负责优先级和节拍中断。

### 3.4 先给简单规则，再变奏

任天堂的关卡访谈和《Super Mario Bros. Wonder》相关分析共同体现了“先让玩家看懂一个动作，再用新环境改变它”的实践。V3 每幕采用引入、确认、变奏、Boss考试；烈祭不重新解释，而是直接把规则交叉。

### 3.5 Boss 是考试，不是血袋

GDC《Boss Up》强调可辨识模式与难度进阶。V3 给 Boss 加入阶段伤害下限和可见章点：玩家的伤害可以提前压到下一阶段边缘，但必须经历规定数量的签名攻击后才能推进。最终 Boss 的后两阶段交替两套攻击，避免重复等待。

### 3.6 难度选择应属于玩家

《Kid Icarus: Uprising》的强度选择实践说明，玩家主动选择风险能增强挑战的正当性。V3 让普通通关后由玩家主动进入“烈祭”，并以独立记录和专属纸色回报，不在普通模式背后偷偷动态加血。

## 4. V3 解决方案

### A. 重写十八个遭遇

普通与烈祭分别拥有九个内容表，而不是共用一张表乘倍率。每关固定三个鼓点，敌人可从不同纵深进入，并可插入扫荡事件。种子只决定左右镜像、门边和有限的路线变体，不改写核心课程。

普通课程：

- 宿场：群体、冲锋、破甲。
- 山社：侧盾、弹幕、裂变与召援。
- 宵祭：编队、危险走廊、综合三拍。

烈祭课程：

- 第一幕立刻把冲锋与密集群叠加。
- 第二幕加入交错半场、三投手和双鼓鬼。
- 第三幕把精英、危险区、召援和冲锋组织为连续组合。

### B. 新增两个关键敌人

- **駆矢鬼**：先显示锁定路径，再高速冲锋；将移动从“随便左右晃”变成明确反应题。
- **鼓鬼**：有限次数召援；让玩家产生优先目标。召援结束后重新前进，避免永久炮台软锁。

投手也改为有限驻留射击，弹数耗尽后继续前进。

### C. 三拍结构与节奏导演

每个遭遇包含三个可见鼓点。空场时道路加速，接敌时速度回落；同时量过高时只降低道路表现速度，不偷偷改变敌人 HP。这样喘息与峰值由内容表控制，又不破坏确定性。

### D. 门从“答案”改为“承诺”

- 关卡作者编排反制／成长两类机会，但不保证绝对安全答案。
- 换边使弃门衰减。
- 充能按时间归一，不让已有 DPS 决定下一次成长速度。
- 第三档需要早决策；烈祭窗口更短。
- 封顶候选自动换成仍有价值的类型。
- 每幕加入专用 Boss 准备门。

### E. Boss 内容保证

- 三个 Boss 分别检验移动、开放半区、综合构筑与祭印时机。
- 每阶段有必须完成的签名攻击数，HUD 以章点显示。
- 阶段转换不再清空攻击和危险区。
- 伤害可以提前压到阶段边缘，但不能删除本阶段内容。
- 紙龍后两阶段交替攻击：弹幕／交叉扫荡、召援／双冲锋。
- 烈祭要求更多阶段模式，并叠加第二轴压力。

### F. 御守与局内行为绑定

- 修复振舞い飯重复结算。
- 大幟增加“优先击杀恢复纸衆”，不再只影响分数。
- 选择池按当前短板、协同和行为改变组织。
- 烈祭关闭自动祭印，迫使玩家主动管理高潮资源。

### G. 难度、记录和奖励

- 普通通关解锁烈祭。
- 普通／烈祭各自记录最高分、等级、时间、通关和局数。
- 烈祭通关解锁“熾紙”，不提供永久战力。
- 金章要求三档门比例和主动祭印次数，防止只靠数值通关。

## 5. 解决后的边界验证

确定性策略代理结果：

| 模式／策略 | 通关率 | 设计含义 |
|---|---:|---|
| 普通・固定中线 | 0/12 | 不选门无法靠初始数值通过 |
| 普通・固定左／右 | 0/24 | 固定路线不能稳定滚雪球 |
| 普通・轻度反应 | 12/12 | 会躲避、会选大致合理门即可看见结局 |
| 普通・迟选门 | 20/20 | 普通允许低门档通关，但全部为非金章 |
| 普通・不用主动祭印 | 20/20 | 辅助自动触发保留可达性，但全部为銀章 |
| 普通・完整反应 | 20/20 | 稳定通关并获得金章 |
| 烈祭・固定中线／固定边 | 0/36 | 静态策略彻底失效 |
| 烈祭・轻度反应 | 2/12 | 能进入但不能稳定完成 |
| 烈祭・迟选门 | 0/20 | 早承诺成为必要能力 |
| 烈祭・不用祭印 | 0/20 | 主动资源管理成为必要能力 |
| 烈祭・完整反应 | 17/20 | 熟练策略显著领先，但仍保留失败压力 |

216 局矩阵没有发生流程超时或软锁。硬模式三次失败集中于鬼車召援与扫荡交叉，属于可解释的战斗失败，不是门序或状态机异常。

## 6. 仍需真人验证的事项

本轮可以证明规则覆盖、策略边界、内容可达性、确定性、响应式和软锁防护；不能用自动代理证明主观乐趣。正式发行前仍需：

1. 让未接触过倍率门游戏的轻度玩家盲玩，确认首扇门在十秒内可理解。
2. 让儿童或低阅读意愿玩家验证敌人剪影、阵形图标和御守微动画是否足够。
3. 让动作游戏熟练玩家验证烈祭的 85% 代理通关边界在人类中是否偏松或偏紧。
4. 在实体 iOS Safari 与 Android Chrome 上验证触控遮挡、音频解锁、震动差异、发热和电量。
5. 进行至少二十局的真人重玩观察，确认左右镜像和 Build 分支能否支撑预期寿命。

在这些测试完成前，V3 可以称为功能和内容完整的 Web 发布候选版，但不应把自动化结果表述为“已证明所有目标玩家都会觉得好玩”。
