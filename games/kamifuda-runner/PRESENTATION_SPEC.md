# 《紙札疾走録・百鬼祭陣 演》表现规格 4.0.0

## 视觉概念
“移动纸芝居祭典”。不是复古滤镜，也不是Neon。场景由和纸底、型染色块、版画线、纸偶接地影和舞台幕组成。二维图形保持一眼可读，材质深度只承担层级与事件重量。

## 面向低阅读意愿玩家
- 一次只突出一个主事件。
- 形状优先于文字：门、危险、敌弹、玩家弹使用不同轮廓。
- 预兆先出现落点和方向，再出现伤害面。
- 正确行为以立即膨胀、破裂、清空和盖印回应。
- 失败原因必须在最后一次受击前已被视觉化。
- 可玩信息不只依赖颜色；红色危险同时使用虚线、箭头、斜纹或形状。

## 动效预算
- 常态：纸纹、微小漂移、单位轻摆。
- 中反馈：门升档、破盾、近身闪避、阵形重组。
- 高潮：祭印、Boss登场、阶段切换、击破、最终结算。
- 同时只允许一个高高潮占据中央视线。

## 无障碍
动效减弱时关闭速度切线、按钮呼吸、扫光和大幅开幕，保留静态预兆、接地影、轮廓和章题。所有关键状态同时使用轮廓或图形编码，不以单一颜色传达。
