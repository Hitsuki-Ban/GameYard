# 《紙札疾走録・百鬼祭陣》设计规格

版本：3.0.0  
入口：`index.html`  
构建：运行 `python build.py` 生成单文件版与完整 ZIP。

## 1. 产品定义

这是一个以“倍率门跑酷能否成为真正成立的短局动作游戏”为课题的离线 Web 游戏。保留倍率门广告最强的部分：

- 一眼可读的左右选择；
- 选择后立刻可见的队伍膨胀；
- 几秒内完成“威胁—成长—验收”；
- 单指或左右键即可操作。

同时删除最常见的弱点：

- 不把门退化为比较两个大数字；
- 不以局外永久攻击力制造数值墙；
- 不允许站在一侧或临门横移稳定通关；
- 不把高难度只做成敌人血量与速度倍率；
- 不让高火力跳过 Boss 的主要内容。

标准一局约 2.5～3.5 分钟，由三幕、九个普通遭遇、三个 Boss、十二次门选择和两次御守选择构成。

## 2. 核心循环

1. **看见预告**：顶部使用真实敌人剪影和攻击运动，而不是只显示文字标签。
2. **提前承诺一扇门**：只有当前所在半区的门会被纸札射击；换边会让原门充能衰减。
3. **以三档完成度穿门**：越早承诺，越可能获得第三档效果。
4. **敌群立即验收选择**：阵形、火力、人数、节奏、结界在下一组敌人中产生不同价值。
5. **通过击杀、近身闪避和拦截积累祭气**。
6. **主动盖下祭印**：清弹、清除轻敌、重创重敌，并取得短时间攻势。
7. **幕间选御守**，将局内行为强化为一个小型 Build。

门阶段与战斗阶段保持短促交替，形成“承诺—兑现—喘息—再承诺”的节拍。

## 3. 四种阵形

| 阵形 | 视觉与足迹 | 规则作用 | 主要验收对象 |
|---|---|---|---|
| 扇阵 | 最宽，广角弹幕 | 对杂兵、裂变体、小鬼有额外伤害 | 密集群、裂变群 |
| 槍阵 | 最窄，集中贯通 | 对铠甲有约六倍于扇阵的有效伤害，可从盾面突破 | 铠甲、盾鬼、Boss 集火 |
| 環阵 | 中窄，旋转纸札 | 真实拦截投射物，并将拦截转化为祭气与得分 | 投手、Boss 弹幕 |
| 鼓阵 | 中宽，低频重击 | 击退命中目标并对周围敌人造成溅射 | 编队、召援、密集精英 |

阵形宽度直接进入敌人、投射物和危险区判定。视觉上的宽窄就是规则，不存在只改变绘制而不改变碰撞的“假阵形”。

## 4. 门系统

### 4.1 门类型

- `札`：人数倍率。
- `筆`：单次火力。
- `拍`：攻击节奏。
- `結`：结界并回收少量纸衆。
- `折`：切换或提升阵形熟练度。

每次门对由关卡作者预先编排，一扇通常解决即将出现的主要压力，另一扇则提供长期成长或不同的解法。普通模式在濒临崩溃时可能把第二项显式替换为结界；烈祭不提供这项援助。

### 4.2 承诺规则

- 中线安全带不攻击任何门。
- 进入左／右半区后，只攻击对应门。
- 换边会让未聚焦门的充能衰减；烈祭衰减更快。
- 充能采用按时间归一化的基础值，不随当前 DPS 指数膨胀。
- 第三档需要在门出现后很早做出决定；烈祭的窗口更短。
- 满门后继续射击会转化为少量祭气；持有“濃墨”时转化效率显著提高。
- 达到人数、火力、节奏或阵形上限后，候选门会被替换，避免死奖励。

## 5. 普通模式关卡课程

每一幕使用“引入—确认—变奏—Boss考试”的职责分配，而不是把九波做成同一走廊的数值换皮。

### 一ノ幕・宿場：建立基础语法

1. **紙の潮**：建立广域清群和人数膨胀的第一印象。
2. **交差駆け**：引入锁定玩家位置后冲锋的駆鬼，要求移动而非站桩。
3. **鉄の護り**：让槍阵的破甲价值变得可见。
4. **大鬼支度**：Boss 前提供槍阵／结界，不让上一波的正确答案反向惩罚 Boss 战。
5. **鬼車**：横向扫荡与高速侧翼，检验移动和集中输出。

### 二ノ幕・山社：空间与投射物

1. **横盾**：盾面方向与换线攻击。
2. **十字火**：有限驻留的投手与弹道拦截。
3. **裂けの儀**：裂变体与鼓鬼召援，要求控制目标优先级。
4. **面打ち**：槍阵／環阵的 Boss 准备门。
5. **屏風面**：左右面具轮流开放，必须读懂开放半区，同时处理半场封锁。

### 三ノ幕・宵祭：综合运用

1. **祭列**：鼓鬼、盾鬼、铠甲与冲锋的编队压力。
2. **墨路**：危险区、投射物和冲锋交叉，检验路径规划。
3. **三つ拍子**：三次短促综合题，回收全部敌人语法。
4. **龍支度**：鼓阵／環阵的最后构筑修正。
5. **紙龍**：三阶段复合考试；最终阶段交替召援与交叉封锁，不能被高 DPS 直接跳过。

## 6. 烈祭：高难度模式

普通模式首次通关后解锁。烈祭不是简单复用普通关卡并提高数值，而是一套独立内容表：

- 九个专用遭遇；
- 更短的门承诺窗口和更快的弃门衰减；
- 独立的敌人编队、重叠预兆、冲锋角度和危险区时序；
- 初始人数 16、结界 1、最大结界 4；
- 敌人 HP、速度与伤害适度提高，但主要难度来自组合和节拍；
- 祭气获取降低 10%，并取消祭印的超时自动触发；
- Boss 每阶段必须完成更多签名攻击，后半阶段使用交替版本；
- 普通模式的濒危结界门导演被关闭；
- 结算与记录完全独立。

烈祭九关：

- 一ノ幕：`裂潮`、`烈・交差駆け`、`鉄鼓`。
- 二ノ幕：`盾輪`、`烈・十字火`、`裂け滝`。
- 三ノ幕：`烈祭列`、`墨迷路`、`終の烈`。

烈祭要求玩家同时掌握六件事：早承诺、阵形克制、预兆换位、优先目标、主动祭印和 Boss 阶段阅读。固定站左、固定站右、临门才选或完全不用祭印均不能稳定通过。

## 7. 敌人职责

| 敌人 | 内容职责 |
|---|---|
| 雑鬼 | 建立人数与广域伤害的爽感基准 |
| 駆鬼 | 压缩反应时间并制造横向波形 |
| 鎧鬼 | 慢速高压前线，要求槍阵或高火力 |
| 盾鬼 | 用方向盾制造换线或破盾选择 |
| 投手 | 远程驻留威胁；射击次数有限，随后继续前进，避免软锁 |
| 裂け鬼 | 常规击杀后分裂，祭印击杀则不分裂 |
| 小鬼 | 裂变后的高速漏怪压力 |
| 駆矢鬼 | 先锁定、显示落点、再冲锋，形成明确的反应测试 |
| 鼓鬼 | 有限次数召援的优先目标，召援完毕后重新前进 |

快敌用于压缩喘息，慢重敌用于占据空间，驻留敌用于改变目标优先级。每一种轮廓、移动和音色都对应其职责。

## 8. 御守 Build

- **早結び**：第三档门阈值降低 10%。
- **無傷の鈴**：无伤清波补一层结界。
- **狐面**：近身闪避与破坏奖励的祭气提高 35%。
- **振舞い飯**：幕间恢复 10% 最大人数；只触发一次，不重复结算。
- **濃墨**：满门后的余射高效转化祭气。
- **折鶴**：一次壊灭保护。
- **残響**：祭印后延长连射强化。
- **大幟**：优先击杀每波最多恢复三次纸衆，并按人数提供得分倍率。

三选一保证至少包含协同、补短或行为改变中的两类；只提供两次选择，避免短局被菜单切碎。

## 9. 评分与长期目标

结果等级：木、朱、銀、金。

金章不是单纯看分数：

- 普通模式要求足够的三档门比例，并主动使用至少三次祭印。
- 烈祭要求更高的三档门比例，并主动使用至少六次祭印。

因此“靠系统自动祭印”或“最后一刻随便穿门”可以看见结局，但不能获得最高评价。

局外成长只解锁纸色，不增加战斗数值。普通通关解锁烈祭；烈祭通关解锁专属“熾紙”配色。普通与烈祭分别记录最高分、最佳等级、最快时间、通关数和游玩数。

## 10. 视觉与音频

视觉不是 Neon，也不使用常见赛博荧光语汇。整体语言来自：

- 和纸底色与纸纤维；
- 木版画式煤黑轮廓；
- 朱砂、群青、黄土、松绿的有限色板；
- 印刷错位、折纸面具、祭札和纸芝居舞台；
- 三幕不同的宿场、山社、宵祭景物；
- 危险区使用墨迹、绳标和纸火，而不是施工警示条。

音频由浏览器实时合成太鼓、拍子木、纸裂与印章层级；不加载外部素材。设置支持静音、触觉开关、减少动态效果和高／低画质。

## 11. 操作

- 鼠标／触摸：横向拖动。
- 键盘：`A/D` 或 `←/→`。
- 祭印：画面右下印章按钮、`Space` 或 `Enter`。
- 暂停：`P`、`Esc` 或画面按钮。

首局第一扇门会显示无文字的左右拖动演示；完成后不再重复。

## 12. 存档与离线性

- 使用版本化 LocalStorage：`kamifuda.runner.profile.v3`。
- 自动迁移 V2 的普通模式记录、设置与纸色。
- 分离版与单文件版读取相同存档来源。
- 游戏不请求外部图片、字体、脚本、音频或网络服务。
