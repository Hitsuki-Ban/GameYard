# PULSE LINK // OVERDRIVE

原创的双盘对战落物网页游戏：连接颜色、制造连锁，并在进攻与防守之间押上全部能量。

[在线试玩](https://hitsuki-ban.github.io/PulseLinkOverdrive/)

指南：[简体中文](docs/GUIDE.zh-CN.md) · [日本語](docs/GUIDE.ja.md) · [English](docs/GUIDE.en.md)

本地运行：

```bash
uv run python -m http.server 8080
```
