# PULSE LINK // OVERDRIVE ガイド

[オンラインで遊ぶ](https://hitsuki-ban.github.io/PulseLinkOverdrive/) · [简体中文](GUIDE.zh-CN.md) · [English](GUIDE.en.md)

## 3つのモード

- **DUEL**：CPUとの通常対戦。どちらかの中央スポーン列が天井に達すると敗北です。
- **BLITZ**：90秒対戦。先にトップアウトしなければ、時間切れ時にスコア、与えたプレッシャー、盤面の危険度で決着します。
- **LAB**：攻撃してこない練習用ターゲットです。ターゲット側のトップアウト時は自動で盤面がリセットされますが、自分の中央列が詰まると終了します。

## 基本ルール

1. 回転できる2個1組のピースを落とします。
2. 同じ色が上下左右に3個以上つながると一緒に消えます。落下後に再び消えると連鎖になります。
3. 白いパルスピースが消去グループに隣接していると巻き込まれ、エネルギーを100獲得します。
4. エネルギーが100以上になると攻撃か防御を選べます。どちらも全エネルギーを消費します。
5. 攻撃は相手の盤面を下から通常の色付き行で押し上げるため、相手の連鎖を助ける場合もあります。防御は接近中の行を先に相殺し、余力で高い位置のピースを減らします。
6. 敗北になるのは中央スポーン列が隠し領域に入ったときだけです。左右はより高く積めます。

## 操作

| アクション       | キーボード        | タッチ                             | 標準マッピングのゲームパッド |
| ---------------- | ----------------- | ---------------------------------- | ---------------------------- |
| 左右移動         | `←` `→` / `A` `D` | 盤面を左右にスワイプ／左右ボタン   | 左スティック／方向パッド左右 |
| ソフトドロップ   | `↓` / `S`         | —                                  | 左スティック下／方向パッド下 |
| 時計回り回転     | `↑` / `X` / `K`   | 盤面をタップ／回転ボタン           | A / Cross                    |
| 反時計回り回転   | `Z` / `J`         | —                                  | X / Square                   |
| ハードドロップ   | `Space`           | 盤面を下へスワイプ／二重矢印ボタン | Y / Triangle／方向パッド上   |
| 攻撃             | `C` / `L`         | 盤面の間にある攻撃ボタン           | R1 / RB                      |
| 防御             | `V` / `;`         | 盤面の間にあるシールドボタン       | L1 / LB                      |
| 一時停止／再開   | `Esc` / `P`       | 右上の一時停止ボタン／再開ボタン   | Start                        |
| タイトルから開始 | `Enter`           | プレイボタン                       | A / Cross                    |

横スワイプは距離に応じて最大5マス移動します。ゲームパッドの表記はメーカーによって異なるため、ここではブラウザの標準マッピング上の位置を示しています。

タイトル画面のモード、難易度、言語、設定はマウス／タッチで選ぶか、キーボードの `Tab` / `Shift+Tab` でフォーカスを移動して `Enter` / `Space` で決定してください。ゲームパッドは開始の決定だけに対応し、これらの項目を移動することはできません。

## GameYard でのアクセシビリティ

設定では音楽、効果音、画面揺れ、動きの軽減、色識別グリフ、触覚フィードバックを個別に変更できます。初回起動時はOSの「視差効果を減らす」設定に従い、色には模様と記号も併用します。音声は最初のクリックまたはキー入力の後に始まります。

言語、音量、モーション低減、画面揺れ、フォーカス、ポーズ、フルスクリーンの方針は GameYard が管理します。ゲームが保存する設定は色パターンと触覚フィードバックだけです。振動とゲームパッドの対応はブラウザや端末によって異なります。
